# Input Schema

## `sample_search_volume.csv`

| Column | Description |
|---|---|
| `date` | weekly or daily date |
| `keyword` | synthetic keyword label |
| `search_index` | synthetic search volume index |

## `sample_dividend_panel.csv`

| Column | Description |
|---|---|
| `date` | observation date |
| `ticker` | anonymized ticker |
| `dividend_yield` | synthetic dividend yield |
| `return_1m` | synthetic next-month return |
| `individual_netbuy` | synthetic individual net-buy measure |
