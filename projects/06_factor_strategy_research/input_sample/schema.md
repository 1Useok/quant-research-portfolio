# Input Schema

## `sample_factor_returns.csv`

| Column | Description |
|---|---|
| `date` | trading date |
| `factor_id` | anonymized factor identifier |
| `daily_return` | synthetic daily factor return |

## `sample_factor_metadata.csv`

| Column | Description |
|---|---|
| `factor_id` | anonymized factor identifier |
| `family` | factor family |
| `turnover` | toy turnover estimate |
| `coverage` | toy stock coverage |
