pandas, numpy만 필요합니다. 이 코드는 선별 논리를 보여주는 공개용 축소판이며, WorldQuant Brain 플랫폼 연동·시뮬레이션 스케줄러·제출 자동화 원본은 공개하지 않았습니다.
