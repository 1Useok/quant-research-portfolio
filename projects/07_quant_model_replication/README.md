# 07. DDQM2 국내 팩터 모델 근사 복제 검산

공표된 상위 종목과 내 모델의 종목이 다르면, 팩터 비중에서 차이가 생겼을까, 같은 비중으로 점수를 매기는 단계에서 생겼을까? 같은 날의 종목 팩터에 **공표 비중을 대입한 순위**(`replay`)와 **직접 예측한 비중으로 산출한 순위**(`predicted`)를 각각 공표 종목 순서(`reference`)와 대조한다.

## 실제 연구에서 확인한 범위

삼성증권 리서치가 발표한 DDQM2 방법론을 바탕으로, 필자는 팩터 비중 예측과 당시 KOSPI200 내 상위 20종목 선정 과정을 근사 복제하고 월간 보고서의 공개 팩터값·비중·추천 목록과 대조했다. 12개 팩터별로 최대 82개 매크로 입력을 쓰는 LightGBM을 학습했고, 월간 보고서 12회에서 회당 공개된 6개 팩터 열을 검산했다. 연구 기록의 마지막 비교일에는 표시 자릿수 기준 종목 팩터 **120/120개**, 매크로 입력 **62/82개**가 일치했다. 월간 보고서 12회 전체의 표시값(12회 × 20종목 × 6팩터)으로 넓히면 **1279/1440개**(88.8%)가 일치해, 마지막 날의 일치가 다른 날짜까지 보장하지는 않는다. 상위 종목은 공표 비중 대입 시 **18/20개**, 후보정을 포함한 비중 자체 예측 시 **14/20개**가 겹쳤다.

당시의 재무 수정 전 값과 매크로 발표 이력, 미공개 학습 설정에는 불확실성이 남는다. 마지막 세 달도 산식 검수에 쓰여 독립 표본 외 검증에 한계가 있다. 아래 실행은 **가상 8종목·3팩터·매크로 1개·18주**로 두 단계의 대조법을 구현한 시연이다. 입력과 공표표, 실행 수치는 모두 합성이다.

## 오프라인 실행

Python 3.10 이상과 표준 라이브러리만 사용하며 외부 패키지는 필요 없다. Windows 11, Python 3.13에서 검증했다. 저장소 루트에서 `code/` 폴더로 이동해 실행한다.

```sh
cd projects/07_quant_model_replication/code
python run_demo.py
python -m unittest discover -s tests -v
```

기본 결과는 `outputs/`의 UTF-8 CSV 5개다. 다른 위치에는 `python run_demo.py --out outputs/check`로 저장한다. 동봉된 합성 CSV 4개는 입력 행 순서와 관계없이 날짜순으로 처리한다. `python data/make_sample.py`를 실행하면 동봉된 합성 CSV 4개와 바이트 단위로 같은 파일을 다시 만든다(난수 없이 결정적 수식으로 생성). [입력 생성 규칙](code/data/make_sample.py)

## 한 주의 정보와 거래 순서

1. **금요일 종가에 신호를 확정한다.** 목요일 관측 종목 중 금요일까지 도착하고 가치·품질·추세에서 두 값 이상이 있는 종목을 쓴다. 매크로는 그 금요일까지 발표된 값 중 가장 최근 관측을 택한다. 5월 10일에는 5월 8일 관측치가 아직 발표 전이라 5월 2일에 도착한 5월 1일 값을 쓴다. [종목 팩터](code/data/factors.csv) · [매크로 발표일](code/data/macro.csv)
2. **성숙한 라벨로 비중을 학습한다.** 각 과거 금요일의 팩터별 상위 2종목 수익률에서 그 팩터가 관측된 적격 종목 전체 수익률을 뺀다. 양쪽 모두 다음 월요일 종가부터 그다음 월요일 종가까지 동일비중으로 계산한다. 비교군 종가가 하나라도 빠지면 해당 라벨은 공란이다. 청산일이 현재 신호일보다 앞선 표본을 팩터별 4개 이상 누적해, 그때 알았던 매크로로 초과수익률(%p)을 회귀한다. 기울기에 릿지 벌점 1을 주고 예측값을 소프트맥스로 비중화한다. 5월 10일 학습은 5월 6일에 끝난 라벨까지 9개씩이다. [학습·점수 코드](code/replica.py)
3. **같은 횡단면을 두 번 채점한다.** 팩터별 백분위는 0~1이며 동률은 평균 순위, 공란이나 유효값이 하나면 0.5다. 비중 가중합에 100을 곱해 내림차순으로 정렬하고 동점은 종목 ID순으로 푼다. 5월 10일 `F05`의 백분위는 (1, 1, 0.5)여서 공표 비중 (15%, 60%, 25%)에서 **87.5점**이다. 상위 3종목에 각각 ⅓을 배정한다.
4. **독립된 가상 공표표와 대조한다.** 가상 발행처의 비중은 ISO 주차에 따라 세 조합을 순환한다. 발행처는 원점수를 20점 간격의 0~4등급(공란 2)으로 바꾼 가중합으로 순위를 정했다. 이 규칙으로 미리 고정한 비중과 상위 3종목을 예측 완료 후 읽는다. 비중은 대입 경로에만, 공표 종목 순서는 대조에만 쓰인다. [가상 공표표](code/data/reference.csv) · [대조 코드](code/run_demo.py)

## 합성 8개 평가일 검산

| 비교 쌍 | 구성종목 교집합 누계 | 같은 순번 누계 | 교집합 최대일(3/3, 동률 모두) |
|---|---:|---:|---|
| 공표표 / 비중 대입 | 21/24 | 13/24 | 5/17, 5/31, 6/7, 6/14, 6/21 |
| 공표표 / 직접 예측 | 20/24 | 7/24 | 5/10, 5/31, 6/7, 6/28 |
| 비중 대입 / 직접 예측 | 19/24 | 12/24 | 5/24, 5/31, 6/7 |

5월 17일 공표 순서는 **F08 → F07 → F02**였다. 비중 대입은 **F07 → F08 → F02**로 종목 3개와 순번 1개를 맞혔다. 직접 예측은 **F07 → F08 → F01**로 종목 2개가 겹쳤고 같은 순번은 없었다. 5월 20~27일의 합성 보유 수익률은 각각 **−0.6969%, −0.4853%**였다. 이 주에는 공표 구성을 더 가깝게 재현한 쪽의 사후 손익이 더 낮았다.

`labels.csv`와 `weights.csv`에서 가용일·라벨 종료일·학습 개수를, `rankings.csv`와 `overlap.csv`에서 두 순위와 교집합 종목 ID를 확인할 수 있다. 피크는 8회 대조 뒤 표시한 최대 교집합 날짜다. `returns.csv`는 별도로 가상 종가의 비용 전 단순수익률을 기록한다. 가상 달력은 평일 휴장을 생략하며 배당·비용·체결 제약도 생략했다. 6월 28일 신호는 7월 8일 청산가가 없어 순위만 검증하고 손익은 공란으로 둔다. 이 합성 손익으로 국내 시장의 알파를 추정할 수 없다. [종가 입력](code/data/closes.csv) · [오프라인 검산 테스트](code/tests/test_demo.py)

## 파일 구성과 입력·출력

```text
07_quant_model_replication/
├── README.md
└── code/
    ├── replica.py          # 시점별 입력 로딩, 성숙 라벨, 릿지 회귀, 순위 산출 (공표표 미사용)
    ├── run_demo.py         # 공표표 결합, 비교, outputs/ CSV 5개 작성
    ├── data/               # 합성 입력: factors.csv, macro.csv, closes.csv, reference.csv, make_sample.py
    └── tests/test_demo.py  # 표준 unittest 9개
```

- 입력(모두 합성): `factors.csv`(종목 144행: 관측일·가용일·종목·value·quality·trend), `macro.csv`(18행), `closes.csv`(144행), `reference.csv`(가상 공표표 8행).
- 출력(`outputs/`, 실행 시 생성되며 저장소에는 포함하지 않음): `labels.csv`, `weights.csv`, `rankings.csv`, `overlap.csv`, `returns.csv`.
- 실제 연구에서 온 것은 위 "실제 연구에서 확인한 범위"의 서술(원문 수치)뿐이다. 코드, 입력 CSV, 공표표, 실행 수치는 모두 이 시연을 위해 새로 만든 합성 자료이며 증권사 보고서 원문이나 실제 시세는 포함하지 않는다.
