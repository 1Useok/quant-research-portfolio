# 01. 한국 기업뉴스 텍스트 신호 — 발표 전 상승, 오버나이트 상승, 익일 장중 반전

**연구 질문.** 뉴스 점수가 높은 종목은 발표 전에 오르고, 종가에서 다음 날 시가 사이에 더 오른 뒤 다음 날 장중에 되돌린다. 이 경로를 *종가 매수·익일 VWAP 매도*로 따라가면 거래비용을 낸 뒤에도 남는가?

한국 경제신문 기사(2006~2025)를 기업 단위로 매핑하고, 지도학습 나이브 베이즈(NB) 점수·텍스트 임베딩·투자자 수급·분봉 가격 경로·체결 용량을 결합해 검증한 원 연구에서, 공개 가능한 부분만 이 폴더에 옮겼습니다. 이 폴더에는 **직접 실행되는 축소 구현(`code/`)** 과 **원 연구의 대표 결과 요약**이 함께 있습니다.

## 실행 가능한 코드 (`code/`)

원 연구의 마지막 단계, 즉 "마감 전에 읽을 수 있었던 뉴스로 종목을 고르고 종가에 사서 다음 거래일 VWAP에 판다"는 규칙을 **합성 데이터** 위에서 끝까지 재현합니다. 기사 75건·가상 종목 8개·10거래일의 합성 표본이며, 원 연구의 원자료나 결과는 들어 있지 않습니다.

- 기사 제목의 기업 별칭 태깅, 중복 제목 제거, 첫 거래일 전에 끝난 라벨만으로 한 번 학습한 NB 점수
- 15:15까지 발표된 기사만 사용하는 마감 시각 규칙, 상위 5종목 선정과 동점 처리
- 종가 매수, 다음 거래일 `거래대금 ÷ 거래량` 청산, 왕복비용(0·20·30bp) 민감도, 청산 지연(결측 VWAP) 처리
- `article_audit → signals → orders → nav` 순으로 추적 가능한 CSV 출력과, 현금·평가액을 독립적으로 다시 계산하는 단위 테스트 7개

```sh
cd projects/01_news_text_strategy/code
python run_demo.py
python -m unittest discover -s tests -v
```

Python 3.10 이상, 표준 라이브러리만 사용합니다(설치 불필요). 설계와 주문 한 건 추적은 [code/README.md](code/README.md)에 있습니다. 합성 표본의 수익률은 원 연구의 성과가 아니라 장부 계산이 맞게 돌아가는지 보여주는 예시입니다.

## 원 연구 결과 요약

아래 수치는 비공개 원자료에서 나온 결과이며 이 폴더에서 재현되지 않습니다. 각 행에 표본 구분과 비용 반영 여부를 적었습니다.

### 임베딩 포트폴리오 (월별 롱숏, MSRR)

기사 `body_200` 임베딩으로 종목-월 신호를 만들고, 팽창창(expanding)으로 추정한 MSRR 가중치로 매월 롱숏 포트폴리오를 구성한 **표본외(OOS) 228개월** 결과입니다. 거래비용은 차감하지 않은 **비용 전(gross)** 수치입니다.

| 모델 (`ff6_residual_embedding_msrr`) | 지표 | 값 |
|---|---|---:|
| `e5_body200` (E5-Mistral) | Sharpe | 1.7007 |
| 〃 | 연율 초과수익률 | 2.2458 (= 224.6%) |
| 〃 | 연율 변동성 | 1.3205 |
| 〃 | 월 평균 초과수익률 t-통계량 | 7.4133 |
| `kure_body200` (KURE) | Sharpe | 1.9996 |

연율 수익률과 변동성이 큰 것은 MSRR 비중을 변동성 목표로 맞추지 않았기 때문이며, 변동성 10%로 환산하면 연 17.0%(E5)·20.0%(KURE)입니다. 같은 기준에서 KURE가 E5-Mistral보다 6개 사다리 모형 모두에서 높았고, 잔차화하지 않은 원 임베딩(`raw_embedding_msrr`)은 Sharpe 0.47(E5)·0.96(KURE)로 낮았습니다. 출처: 원 연구의 `e5_body200_msrr_summary.csv`, `e5_mistral_body200_vs_kure_summary.md`.

### 체결 용량 모형 (종가·익일 시가 경매 거래대금 예측)

| 항목 | 값 | 구분 |
|---|---:|---|
| 표본 (경매·가격·시가총액 병합 후 이벤트 수) | 94,230 | 2014~2025, 일·종목별 첫 장중 뉴스 |
| 표본외 관측치 | 70,952 | OOS 2019~2025 |
| `hgb_mean` OOS R2 | 0.2076 | 20일 중앙값 기준선 대비 로그 용량 예측 개선도 |
| `ridge` / `hgb_q30` | 0.1077 / 0.1214 | 같은 기준 |

R2는 "예측값이 실제 용량을 20% 설명한다"는 뜻이 아니라 기준선(자기 종목 최근 20일 중앙값) 대비 제곱오차 감소율(`oos_r2_vs_baseline`)입니다. 용량은 `min(당일 종가 경매 거래대금, 익일 시가 경매 거래대금)`으로 정의했고 수익률이 아닌 거래 가능 규모의 예측입니다.

### 투자자 수급 채널 (일별 Fama-MacBeth, 뉴스 종목-일)

`NB_score_z`(일별 표준화)를 설명변수로 한 회귀 계수이며, 포트폴리오 성과가 아니라 비용과 무관한 통계 결과입니다.

| 종속변수 | 계수 | t |
|---|---:|---:|
| 개인 거래활동 비중(%p) | 1.169 | 35.53 |
| 개인 매수대금/거래대금 | 0.988 | 25.56 |
| 개인 매도대금/거래대금 | 1.350 | 34.66 |
| 개인 매수-매도 불균형 | -0.0039 | -8.65 |
| 발표 전 5일(t-5~t-1) 수익률(bp) | 79.38 | 35.00 |

| NB 점수 분위(일별) | 발표 전 t-5~t-1 수익률 | 뉴스 당일 수익률 |
|---|---:|---:|
| Q1 (최저) | -0.12% | -0.32% |
| Q5 (최고) | 2.47% | 1.82% |

해석은 원 연구의 결론을 따릅니다. 고점수 뉴스는 개인의 거래활동을 높이지만 개인은 순매도이고, 발표 전 상승에는 기관·외국인 순매수가 정합적입니다. 다만 특정 투자자가 가격을 움직였다는 인과 증거는 아니며, 분봉 사건 표본에서는 보험·투신·연기금 세 유형의 유의성이 동시에 재현되지 않습니다.
