# 장중 기업뉴스 Top 5 포트폴리오

**뉴스 점수가 높은 종목은 발표 전에 오르고 종가~다음 날 시가에 더 오른 뒤 장중에 되돌린다. 이 경로를 종가 매수·익일 VWAP 매도로 따라가면 비용 후 남는가?** 원 연구가 보인 이 경로의 뒷부분(마감 전 뉴스로 종목을 고르고, 종가에 사서 다음 거래일 장중 VWAP에 파는 구간)을 작은 포트폴리오로 재현한다. 같은 종목 선정을 유지한 채 비용만 바꾸고, 각 주문이 일별 순자산(NAV)에 반영되는 과정을 확인할 수 있다. 발표 전 상승과 발표 후 장 마감까지의 움직임은 모형화하지 않고, 종가 이후(오버나이트 구간과 다음 날 VWAP까지의 장중 되돌림)에서 나는 손익만 장부에 남긴다.

**모든 기사, 기업, 가격, 거래량과 학습 라벨은 이 예제를 위해 만든 합성 데이터다.** 기사 점수는 공개 예제용 나이브 베이즈(NB)로 계산한다. 아래 수익률과 낙폭은 합성 표본 10거래일의 장부 결과다.

## 실행

Python 3.10 이상에서 표준 라이브러리만 사용하며 `pip install`이 필요 없다(Python 3.13에서 확인). 저장소 루트에서 이 폴더로 이동한 뒤 실행한다.

```sh
cd projects/01_news_text_strategy/code
python run_demo.py
python -m unittest discover -s tests -v
```

첫 명령은 `data/`의 CSV 4개를 읽어 기사별 처리 내역부터 포트폴리오 성과까지 `outputs/`에 CSV 5개를 만든다. 다른 왕복비용을 비교하려면 `python run_demo.py --cost-bps 0 10 50 --out outputs/alternative`를 실행한다. 1bp는 거래금액의 0.01%다.

## 기사에서 주문까지

1. **입력과 태깅.** 수집을 마친 기사 피드를 본뜬 CSV에서 시작한다. 발행시각을 한국시간으로 맞추고, 제목에 등장한 현재명·별칭이 가상 종목 하나로 연결되는 기사만 채택한다. 같은 종목·거래일에 공백·문자 폭을 정규화한 제목이 같으면 먼저 들어온 기사를 유지한다. [기사 75건](data/news.csv) · [종목과 별칭](data/companies.csv)
2. **시점과 점수.** 첫 거래일 전에 수익률 관측이 끝난 합성 문장 20개로 NB를 한 번 학습해 고정한다. 가상 정규장은 09:00~15:30이고, 09:00부터 **15:15:00까지** 발표된 기사의 상승 클래스 점수만 기업별로 평균한다. 높은 순으로 최대 5종목을 고르고 동점은 종목코드순으로 정한다. [학습 표본](data/training.csv) · [신호 코드](signals.py)
3. **매수와 청산.** 초기 현금은 100만 원이다. 같은 예산을 배정한 순위 자리 5개에서 종가에 매수하고, 다음 거래일부터 `세션 거래대금 ÷ 거래량`으로 청산한다. 매수가격이 비면 그 자리는 현금으로 둔다. 매도 VWAP가 비면 기존 종목을 계속 보유하고 같은 순위의 새 매수를 건너뛴다. [가상 시세 80행](data/market.csv) · [체결·장부 코드](backtest.py)
4. **손익 계산.** 왕복비용을 양쪽 체결금액에 절반씩 부과한다. 현금과 종가 평가액을 더해 NAV를 계산하고, 평가 종가가 비면 마지막 관측 종가를 쓴다. 같은 날 VWAP 청산대금의 종가 매수 재사용, 소수점 수량, 무배당·무이자를 가정한 일별 모의 체결이다. [실행 코드](run_demo.py)

## 합성 표본 결과

8종목·10거래일에서 기사 75건 중 68건을 채택했다. 총 43개 순위 중 41개가 매수됐으며 마지막 거래일까지 모두 청산됐다. 아래는 연율화하지 않은 **기간 누적수익률**과 초기 현금부터 측정한 최대낙폭이다.

| 가정한 왕복비용 | 기간 누적수익률 | 최대낙폭 | 매수 / 매도 체결 |
|---:|---:|---:|---:|
| 0bp | +3.04% | −0.41% | 41 / 41 |
| 20bp | +1.36% | −0.76% | 41 / 41 |
| 30bp | +0.53% | −0.94% | 41 / 41 |

`outputs/summary.csv`에서 같은 수치를 확인할 수 있다. 테스트 7개는 학습 라벨의 시간 경계, 뉴스 마감 시각, 중복·동점 처리, 청산 지연을 점검하며, 매수·매도 수량과 수수료만으로 매일의 현금과 평가액을 독립적으로 다시 계산한다. [검증 코드](tests/test_demo.py)

## 입력·출력·파일 구성

- **입력(`data/`, 모두 합성).** `news.csv`(article_id, published_at, headline), `companies.csv`(symbol, aliases), `training.csv`(label_end, headline, synthetic_return), `market.csv`(session, symbol, close, traded_value, volume; 빈 칸은 관측 결측).
- **출력(`outputs/`, 실행 시 생성되며 git에는 포함되지 않음).** `article_audit.csv`, `signals.csv`, `orders.csv`, `nav.csv`, `summary.csv`.
- **코드.** `signals.py`(NB 학습·기사 채택·순위), `backtest.py`(체결·NAV 장부), `run_demo.py`(CSV 입출력과 실행), `tests/test_demo.py`(단위 테스트 7개).

## 합성 데이터와 원 연구의 구분

기사, 기업, 가격, 거래량, 학습 라벨은 전부 이 폴더를 위해 만든 합성 데이터이며 실제 시장·뉴스 자료나 원 연구의 원자료는 포함하지 않는다. 원 연구에서 가져온 것은 "마감 전 공개 뉴스로 종목을 고르고 종가 매수·다음 거래일 VWAP 청산 후 비용 민감도를 본다"는 설계뿐이며, 위 표의 수치는 원 연구의 결과가 아니라 합성 표본의 장부 결과다.
