# 04. 기업특성으로 월별 롱숏 포트폴리오 만들기

재무·가격 기업특성으로 다음 12개월의 위험조정 성과를 분류해 월별 롱숏 포트폴리오를 만들 수 있을까? 국내 주식에 Jensen–Kelly–Pedersen(JKP) 기업특성을 적용한 ML 연구에서, **월말에 보이는 원계정 한 줄이 다음 투자일의 목표 비중이 되기까지**를 작게 옮긴 구현이다. 다음 12개월의 위험조정 성과를 분류하도록 모델을 학습하고, 매월 예측확률 순위로 롱과 숏을 구성한다.

**종목·가격·재무 계정은 전부 합성 데이터다.** 원 연구에서 사용한 공통 데이터 저장소, 특성 검토, 학습, 포트폴리오 구성의 경계를 유지했다. 이 코드는 기업특성 네 개, 소형 XGBoost 분류기, 동일비중 롱숏으로 실행한다. 최신 결과물은 다음 세션에 적용할 모의 목표 비중이다.

## 실행

Python 3.13에서 검증했다(`numpy==2.4.1`이 3.11 이상을 요구하므로 3.11 이상이 필요하다). 의존성은 `requirements.txt`의 `numpy==2.4.1`, `pandas==2.3.3`, `scikit-learn==1.8.0`, `xgboost==3.1.3`이다. 저장소 루트에서 `code/` 폴더로 이동해 다음 명령을 실행한다.

```sh
cd projects/04_jkp_ml_longshort/code
python -m pip install -r requirements.txt
python run_demo.py
python -m unittest discover -s tests -v
```

`outputs/2024-12-31/`에 CSV 8개가 생긴다. `python run_demo.py --as-of 2024-11-30`을 실행하면 12월 증분을 읽기 전의 결과가 별도 폴더에 만들어진다. 같은 기준일의 같은 결과는 그대로 재사용한다. 기존 결과와 내용이 다르면 `--out`으로 별도 경로를 지정할 수 있다.

## 원천 데이터에서 목표 비중까지

| 단계 | 처리 기준 | 직접 확인할 결과 |
|---|---|---|
| 1. 데이터 등록 | 가상 종목 16개의 월별 시장 기준본과 등록된 증분을 결합한다. 동일 종목·월의 동일 관측은 한 번만 반영하고 값이 충돌하면 중단한다. 재무는 연간·분기 원계정과 결산일을 읽는다. | `input_audit.csv` |
| 2. 특성 계산과 패널 | 연간 재무는 결산 4개월 뒤, 분기 재무는 3개월 뒤 월말부터 사용한다. 해당 월의 마지막 관측 가격으로 특성을 계산한다. 한 행의 고유키는 `security_id`와 다음 달 첫 세션인 `effective_date`다. | `feature_panel.csv` |
| 3. 학습 대상 생성 | 신호월 이후 12개 연속 월별 종가수익률에서 월 무위험수익률 0.1%를 차감한다. 표본 표준편차로 계산한 연율화 Sharpe가 0.5 이상이면 1이다. 12개 관측이 완성되는 `label_end`를 별도로 보존한다. | `labels.csv` |
| 4. 연도별 학습과 예측 | 투자연도마다 직전 12월 말까지 결과가 확정된 라벨로 XGBoost를 학습한다. 성숙일 기준 최대 10년, 최소 24개 신호월과 두 클래스가 필요하다. 각 투자월은 해당 연도 모델로 점수화한다. | `annual_fits.csv`, `predictions.csv` |
| 5. 포트폴리오 | 신호월 시가총액 상위 60% 안에서 확률 상위 2종목은 각각 +25%, 하위 2종목은 각각 −25%로 정한다. 다음 달 첫 세션 시가에 리밸런싱하고 그다음 달 첫 시가까지 보유한다. | `target_weights.csv`, `backtest.csv`, `latest_paper_targets.csv` |

### 어떤 정보를 언제 사용했는가

| 특성 | 월말 계산식 | 입력 시점 |
|---|---|---|
| `be_me` | 양수 장부자본 ÷ 시가총액. 시가총액은 종가 × 발행주식 수 | 반영 가능한 최근 연간 재무와 신호월 종가 |
| `at_gr1` | 총자산 ÷ 정확히 1년 전 총자산 − 1 | 반영 가능한 연간 재무 |
| `niq_at` | 해당 단독분기 순이익 ÷ 직전 분기 총자산 | 반영 가능한 분기 재무 |
| `ret_6_1` | 신호월 직전 5개 월수익률의 복리 수익률 | 당월을 건너뛰고 `t−5`부터 `t−1`까지 |

예를 들어 2024년 12월 말 `SIM12`의 `be_me` 분자는 **2023년 12월 결산 장부자본 81,408,092,140원**이다. 이 값은 2024년 4월 말부터 사용 가능하다. 12월 말 가상 종가 182,474.25원과 발행주식 11,765,548주를 적용하면 `be_me`는 약 **0.037919**다. 같은 행의 분기 수익성에는 2024년 9월 분기를 쓴다. 이 행의 투자 적용일은 **2025년 1월 2일**이다.

네 특성 중 세 개 이상 관측된 종목을 점수화한다. 결측은 같은 신호월의 중앙값으로 보완하고 횡단면 순위를 만든다. 전체가 결측인 열은 중립값을 부여한다. 표준화와 분류기 적합은 해당 연도의 학습행에 한정한다. 학습 라벨의 12개월 관측 기간과 포트폴리오의 한 달 보유 기간은 각각 예측 목표와 투자 결정을 나타낸다.

### 운용을 준비할 때 확인할 출력

기본 실행에는 1,728개 종목·월, 학습 완료 모델 7개, 양끝 시가가 관측된 보유 구간 71개가 있다. 2024년 12월 말의 최신 4개 목표 비중은 그날 알 수 있는 자료로 산출한다. 해당 종목의 향후 12개월 라벨은 이때 비어 있다. 종목 선정 뒤에만 보유기간 가격을 결합한다.

비용은 실제 가격 변동을 거친 직전 포지션에서 목표까지 바꾸는 금액에 편도 10bp를 적용하고, 숏 명목금액에 연 2% 대차료를 일할 계산한다. 수익률은 두 시가가 관측된 보유 구간까지 집계한다. 첫 진입 비용을 포함하며 마지막 기록은 다음 리밸런싱 직전 평가액이다. 가상 달력은 주말과 1월 1일을 쉬는 규칙이며, 가격은 배당·기업행사가 없는 가상 보통주를 가정한다. 재무의 고정 반영 시차는 합성 표본의 규칙이다. 실제 공시·정정 시각을 재현하려면 버전별 원천 기록이 필요하다.

테스트 6개는 네 특성을 원계정으로 손계산하고, 라벨 성숙일과 학습 마감일을 대조한다. 12월 시장 증분을 추가해도 11월까지의 특성·확률·비중·완료 손익이 같은지, 누락된 체결가나 충돌하는 원계정이 조용히 통과하는지도 검사한다. [검증 코드](code/tests/test_pipeline.py)

## 입력·출력·파일 구성

- **입력(`data/`, 모두 합성).** `market_base.csv`·`market_delta.csv`(signal_eom, security_id, first_open, last_close, shares), `financial.csv`(fiscal_end, security_id, frequency, assets, book_equity, quarter_income), `calendar.csv`(signal_eom, first_session, last_session), `registry.csv`(kind, file, published_through). `data/make_sample.py`가 고정 시드(4117)로 이 파일들을 다시 만든다.
- **출력.** `outputs/<기준일>/`의 CSV 8개(`input_audit`, `feature_panel`, `labels`, `annual_fits`, `predictions`, `target_weights`, `backtest`, `latest_paper_targets`). 실행 시 생성되며 git에는 포함되지 않는다.
- **코드.** `data_pipeline.py`(입력 등록·특성·패널), `model.py`(라벨·연도별 XGBoost), `portfolio.py`(목표 비중·비용 반영 손익), `run_demo.py`(실행과 결과 게시), `tests/test_pipeline.py`(테스트 6개).

## 합성 데이터와 원 연구의 구분

종목(`SIM01`~`SIM16`), 가격, 발행주식 수, 재무 계정, 달력은 모두 난수로 만든 합성 데이터이며 실제 시장·재무 자료는 들어 있지 않다. 원 연구에서 가져온 것은 JKP 기업특성의 정의 일부, 원천 등록→특성 검토→학습→포트폴리오로 이어지는 경계 구조, 점시점(point-in-time) 원칙뿐이다. 합성 데이터에는 신호가 의도적으로 심겨 있지 않으므로 `backtest.csv`의 손익은 원 연구의 성과를 뜻하지 않는다.
